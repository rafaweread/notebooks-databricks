# 📓 notebooks-databricks

> Ambiente de estudos do curso de **Databricks** da [Alura](https://www.alura.com.br/), onde concentro todos os scripts dos cursos de **Python**, **Spark** e **Databricks** desenvolvidos na plataforma Databricks.

## 📖 Sobre

Este repositório reúne os notebooks e scripts produzidos durante minha jornada de aprendizado na plataforma Databricks. Aqui estão documentados os exercícios, experimentos e projetos práticos dos cursos de Python, Spark (PySpark e Spark SQL) e Databricks, servindo como material de consulta e registro de evolução.

## 🗂️ Estrutura do Repositório

```bash
notebooks-databricks/
├── curso_alura/          # Scripts dos cursos da Alura (Python, Spark e Databricks)
├── ciencia_de_dados/     # Notebooks de ciência de dados (EDA, análises exploratórias)
├── data_analyst_prouni/  # Análises de dados com datasets do PROUNI
├── query_sql/            # Consultas SQL e exercícios de Spark SQL
├── lab/                  # Laboratórios e experimentos diversos (Joins, pipelines, etc.)
└── README.md
```

## 🚀 Tecnologias e Ferramentas

* **[Databricks](https://www.databricks.com/)** — plataforma de data analytics utilizada em todos os estudos
* **Python** — linguagem principal dos notebooks
* **PySpark** — processamento distribuído de dados
* **Spark SQL / SQL** — consultas e análises de dados
* **Delta Lake** — arquitetura lakehouse (quando aplicável)

## 📚 Conteúdo Estudado

* Fundamentos de Python para análise de dados
* Criação e manipulação de DataFrames (PySpark)
* Leitura de arquivos CSV, TXT e JSON
* Streaming de dados
* Sintaxe de JOINs e consultas SQL
* Pipelines de dados (camada bronze, silver e gold)
* Análise exploratória de dados (EDA)

## ⚙️ Como Executar

Os notebooks deste repositório foram desenvolvidos na plataforma **Databricks**. Para executá-los:

1. Faça login em um workspace do Databricks
2. Importe o notebook desejado (opção *Import* no menu do workspace)
3. Anexe um cluster ou utilize compute serverless
4. Execute as células do notebook
